# K Beauty AFG

فروشگاه آنلاین محصولات اورجینال کره‌ای مراقبت پوست (Next.js).

## اضافه کردن یا تغییر محصول

همهٔ محصولات در فایل `data/products.json` هستند. برای اضافه کردن محصول، یک بلوک `{ ... }` را کپی کنید و این‌ها را عوض کنید:

| فیلد | معنی |
|---|---|
| `slug` | آدرس صفحهٔ محصول، انگلیسی و بدون فاصله (مثال: `cosrx-snail-essence`) |
| `name` | اسم محصول |
| `brand` | برند |
| `type` | یکی از: `cleanser` `sunscreen` `serum` `cream` `mask` |
| `skin` | نوع پوست: `oily` `dry` `combination` `sensitive` |
| `price` | قیمت به عدد (مثال: `1500`). اگر هنوز معلوم نیست: `null` |
| `size` | حجم |
| `image` | آدرس عکس (مثال: `/products/snail.jpg`، عکس را در پوشهٔ `public/products` بگذارید) |
| `bestseller` | `true` اگر در «پرفروش‌ها» نشان داده شود |

## تنظیمات فروشگاه

اسم فروشگاه و آیدی اینستاگرام در `data/site.json` است.
